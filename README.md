# 亂畫一通救貓咪

用手指畫一筆歪歪的線，幫小貓過水坑、接小魚、躲大雨。成功靠創意，失敗也要好笑。

目前已有三關 H5 早期試玩原型；畫面與玩法仍在調整，尚未推出 Google Play 版本。

- [遊戲企劃書](GAME_DESIGN.md)
- [畫線救貓情境圖](assets/draw-to-rescue-concept.jpg)
- [開啟 H5 線上試玩](https://poyueh.github.io/draw-to-rescue-cat/)
- [H5 試玩檔](index.html)：也可用靜態網站伺服器開啟。

遊戲支援手機觸控與電腦滑鼠；畫一筆後放開即可開始。提示、重新開始與音效開關都在畫面上。
